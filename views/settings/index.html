角色

内置角色只读；新建角色后可上传立绘和差分。点击角色卡片切换。

立绘按高度缩放，宽度自适应；不同尺寸的图片用这两个滑块调到人物不被对话框挡住、也不超出画面。

立绘与差分

支持 PNG / JPG / WebP / GIF，单张 ≤ 12MB。未设置的表情会回退到“默认”。

背景库

选择“跟随背景模式”后，会话内会从背景库里选一张并保持；选具体背景则固定使用它。

怎么用

  1. 在左侧「角色」里新建一个角色，先上传「默认」立绘，再给开心 / 兴奋 / 平静 / 难过 / 生气 / 惊讶 / 害羞 / 害怕 / 担心 / 疲惫 / 温柔 / 得意 / 困惑 / 无语 / 坏笑 / 感动 / 厌恶 / 好奇上传差分。
  2. 不是每个情绪都要单独一张图：在某个情绪卡片的「上传新图」下拉里选一张已经上传的立绘，就能让多个情绪共用同一张图。
  3. 拖动右侧滑块，让立绘的头和肩膀落在画面里、下半身被对话框自然挡住；点「保存位置」。
  4. 到「背景」上传自己的背景图，点选即可固定；也可以保留「跟随背景模式」。
  5. 「外观」里改角色名标签、自由输入位文案和对话框透明度。
  6. 内置角色只读，但位置可以调；想换自己的形象请新建角色。

文件放在哪

资源在 data/plugin_data/astrbot_plugin_gal_choice/：assets/characters/ 是角色差分，assets/backgrounds/ 是背景。更新插件不会清空这个目录。

排障

如果预览一直转圈，先确认 AstrBot 的文转图服务正常；出图失败会在右侧提示。上传后如果没有立刻变化，点右上角「刷新状态」。
